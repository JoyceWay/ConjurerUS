卖给 AI Agent：最好的客户不是人

Dru Riley 的 A 级客户理论：agent 按次付费、越干活付越多；附 5 个一人公司能抄的 B2B 数据副业、3 道护城河与 30 天冷启动 SOP。

来源：Dru Riley（2026-11-09）· Marc Lou TrustMRR 案例 11 CONJURER.US

01 / 最好的客户不是人

Dru Riley 花 6 年研究商业模式，按“谁付钱”给生意打分。

消费者是 C，企业是 B，agent 是 A。

企业比消费者强在四点：更急、付更多、预算更大、取消更少。

Agent 比企业更强。

Dru Riley 的打分逻辑很简单：谁付钱，谁就是最好的客户。消费者付小钱还总取消，企业付大钱但要销售慢慢谈，agent 既付得多又不用谈。

它在主人睡觉时工作。

它接了活就固定用同一个工具。

它按每次任务付费，活干两倍就付两倍。

Dru Riley 说，卖给 AI agent 的生意里，大约有 $100M / 年的收入等着人来拿——搜索引擎 Exa 用约 3 年就走到了这一步。

IDC 预计，AI agent 将从 2025 年约 2,900 万个涨到 2030 年超过 20 亿个，每天新增约 120 万个，比每天出生的婴儿多 3 倍多。

更关键的是，agent 不会货比三家、不会砍价、不会流失到竞品——它一旦选定一个工具，就会一直用下去。

消费者付小钱、取消快，企业付大钱、预算足，而 agent 在主人睡觉时工作、按次付费、越干活付越多。

02 / 六个数字：agent 真的在付钱

Exa：为机器做的搜索引擎，按次收费，约 3 年做到 $100M / 年，普通 B2B 软件公司要 9 年。

Daytona：2025 年为 AI agent 从零重做，不到 50 天冲到 $1M / 年的 pace，此后月增约 51%，多数客户自助注册。

Neon：Replit 接入后每天新建约 10 个数据库；Replit 推出建应用的 AI agent 后，Neon 一天新建 13,000 个数据库，多数来自从没听说过 Neon 的人。

Vercel：Claude Code 部署 JavaScript 应用每次都选 Vercel；编程 agent 占其新业务的比例，从 2026 年初不到 3% 涨到 10 月约一半。

Resend：同一测试里，Claude Code 选 Resend 的次数是老牌 SendGrid 的约 9 倍——agent 固定选同一工具，赢者通吃。

Ahrefs：AI 模型只带来 0.5% 的访客，却带来 12.1% 的注册。

还有一个关键机制：net-negative churn（负流失）。

Agent 干得越多付得越多，按次收费让“留下的客户多花的钱超过流失客户带走的钱”成为可能。

如果客户的 agent 下个月干两倍的活，你不用再卖任何东西，就多收一倍的钱。

六个案例讲的是同一件事：agent 不看广告、不读落地页、不跟销售聊天，它只认一个东西——哪个工具能把活干完。干完一次，下次还用同一个。

这就是为什么卖给 agent 是 A 级生意：客户自己长出来、自己留下来、自己越花越多。

03 / 模型：一座 AI 数据收费站

互联网是为人建的：搜 Google、读落地页、约演示、跟销售聊、再买单。

Agent 不走这条路。

它接了任务就直接干活，干完就付费。

所以能卖给 agent 的生意，长这样：一份高频变动、极度分散、离交易极近的结构化数据，agent 每天定时来查，按次付费。

静态榜单和导航站卖不动——爬虫抓一次就再也不来了。

只有每天都在变、别处拼不齐、离钱最近的数据，才值得 agent 天天回来掏钱。

三个特征缺一不可：高频变动，数据每天都在变，昨天的值今天就过时；极度分散，数据散在上千个源头，没人愿意一个个去拼；离交易极近，查完数据下一步就是下单、付款、签约，agent 付费的动力最强。

对一人公司来说，这套模型最友好：不需要销售团队、不需要约演示，agent 自己找上门、自己付费、自己续费。

这套模型已经有人跑通了：Marc Lou 的 TrustMRR 靠只读支付密钥验证真实收入，首年收入 $427,610，平台上完成 208 单收购（详见[案例拆解 11](https://x.com/HustleAesthete/status/2117805206226538764)）。

别再给爬虫修免费高速公路了，在出口处建好你的 API 收费站。

04 / 5 个可抄的 B2B 数据副业

这 5 个方向，任何一个跑通都能做成月入 $5k–$20k 的小而美现金牛。

💡 点子 1：全球大模型 API 与 SaaS“真实限流 / 隐藏涨价”实时监测库

企业级 AI Agent 执行任务时，常撞上接口延迟飙升或 SaaS 悄悄改免费层限额，写代码选型时急需知道哪家最稳、性价比最高。对 agent 来说，选错接口等于任务失败、重试烧钱，所以它愿意为一份实时可信的“路况”付费。写一套定时拨测脚本，每 15 分钟测主流 API 的真实首字延迟与吞吐量，同时监控上千家 SaaS 的定价页与条款页变动。网页公开基础榜单引流，高频调用走付费 MCP Server 按次计费，同时向云厂商收“高可用推荐位”赞助费。

💡 点子 2：独立站 / 网红带货真实 ROI 与退货率透明库

品牌方用 AI Agent 找网红投放，最怕刷量假号，急需真实转化率、千次播放成交额与退货率。投错一个假号等于预算打水漂，所以这份真实数据是刚需。做一个免费工具，让创作者接入 Shopify、TikTok Shop 或 YouTube Studio 的只读分析 API，自动生成一张带官方防伪水印的 Verified Media Kit。创作者为了接高价商单，会主动把这张战报卡挂在自己简介里，等于免费帮你分发；创作者完全免费，向批量抓取数据的品牌公关公司、MCN 与营销 Agent 收 $99 / 月 API 订阅费或撮合抽成。

💡 点子 3：跨境合规与硬件认证“动态避坑”结构化字典

跨境卖家的选品 Agent 每天查：某款产品发往欧盟或美国最新要什么认证？最近海关扣留了哪些品类？各国政府官网格式混乱，全是 PDF 扫描件。查错一次等于整批货被扣，损失远大于一份订阅费。用 Python 加多模态大模型每天自动抓取海关通报、产品召回公报、禁售政策 PDF，清洗成高度标准化的 JSON 字段（HS 编码、违规原因、罚款金额、替代方案）。免费放出前 3 条预览，大批量抓取触发限流，弹提示接 Webhook / JSON API，$49 / 月。

💡 点子 4：开源软件与 AI 框架“破坏性更新”实时补丁库

大模型写代码最怕知识库过期：协议刚更新，AI 还在用两年前废弃的函数，导致疯狂报错。用错一个废弃函数等于整段代码跑不通、反复报错烧掉大量 Token，所以编程 agent 愿意为最新语法付费。监控 GitHub Top 1,000 热门开源库的 Release Notes、Commits 与热门报错 Issue，用 AI 自动提炼成专为编程 Agent 设计的“新旧代码迁移对比块”。打包成轻量级付费 MCP Server 或 llms-full.txt 订阅源，程序员在 Cursor 或 Claude Code 里配置你的 API Key，$9 / 月，从此 AI 写代码永远调用最新语法，不再出现幻觉。

💡 点子 5：垂直行业 B2B 采购“真实成交底价”众包账本

企业买 Salesforce、AWS 或律所服务，官网永远只写“Contact Sales”，采购谈判 Agent 极想知道别人到底拿了几折。谈判时多知道一个点的折扣，省下的钱就是几十倍订阅费。采用 Glassdoor 式的“匿名以物换物”机制：企业采购员上传一份脱敏的真实采购发票或合同截图（由 AI 自动 OCR 核验真伪并抹去公司名），即可免费解锁查看同行业其他公司的真实成交底价。不仅人类采购总监抢着付费解锁，专门帮企业砍价的代理机构与财务审计 AI 也会按年采购你的 API 数据流。

05 / 护城河：3 道防白嫖铁闸

辛苦洗了 1 万条数据，别人写个 Python 脚本 10 分钟全爬走，再也不来了——这是数据站最常见的死法。

想躺着收月租，架构里必须埋 3 道闸：

只卖“流动的活水”，不卖“静态的死水”。

页面必须有高频跳动的时间戳字段（如 last_verified：12 mins ago、7 日增长斜率、实时状态）。昨天爬走的数据今天就失效，逼对方只能买实时 API 订阅。

软拦截漏斗（The 429-to-API Funnel）。

永远别用验证码把爬虫一棍子打死。Cloudflare 检测到某 IP 1 分钟内连续请求超 15 次时，别返回 403，而是返回一段 JSON 营销话术，引导对方买 $29 / 月的实时 JSON 流 + Webhook：

{"status": 429, "message": "Hey Developer/Agent! Parsing HTML is painful and rate-limited. Get clean, real-time JSON stream + Webhook for just $29/mo at https://yourdomain.com/api"}

把每一个来偷数据的爬虫，当成最精准的付费 API 潜在客户。

金丝雀蜜罐（Canary Traps）。

免费 HTML 页随机插入 1%–2% 带特定拼写特征的“虚拟测试条目”（付费 API 中自动剔除）。竞品原样照搬，一封附带铁证的 DMCA 版权投诉直接让对方域名下架。

三道闸的共同逻辑只有一个：让免费的东西刚好够尝味道，让真正值钱的东西只能按月租走。

06 / 30 天冷启动 SOP 与武器库

Week 1：数据源与入库

选一个你懂的细分领域，定好第一个数据源；写定时抓取脚本，把数据洗成标准化 JSON，进数据库。

Week 2：Next.js pSEO 与 llms.txt 部署

每条数据自动生成标准化 URL 页面；根目录部署 /llms.txt 与 /llms-full.txt，用纯 Markdown 给大模型提供全站索引。

Week 3：验证徽章外链裂变

上线“验证徽章”机制：用户接入数据，就能拿到一枚可嵌入官网的动态徽章，徽章挂到哪，外链就长到哪。

Week 4：API 收费墙与交易撮合上线

免费页限流，付费 API 开放；挂牌与撮合功能上线，收第一笔交易费。

4 个周末，一人一台电脑，不需要团队。

核心技术武器库

llms.txt 规范：在网站根目录部署 /llms.txt 与 /llms-full.txt。官方标准：llmstxt.org

Schema.org 与 JSON-LD 结构化标记：Google 与主流大模型最信赖的实体声明格式。官方文档：schema.org/docs/documents.html；调试沙盒：json-ld.org/playground、validator.schema.org

Cloudflare AI Crawl Control 与 Pay Per Crawl：监控哪些 AI 爬虫在抓站，针对未付费爬虫返回 HTTP 402 Payment Required。官方文档：developers.cloudflare.com/ai-crawl-control

Model Context Protocol（MCP）：AI 应用的“USB-C 接口”，半天就能把 Supabase 数据库封装成远程 MCP Server。官方入门：modelcontextprotocol.io/docs；参考 Server：github.com/modelcontextprotocol/servers

数据采集与清洗：Firecrawl（任意网页转 LLM-Ready Markdown / JSON）：docs.firecrawl.dev；Apify（云端爬虫构建与变现商城）：docs.apify.com

建站与计费网关：Next.js 动态路由与 SSR / SSG：nextjs.org/docs；Unkey / Zuplo（API Key 鉴权、限流与按量计费）：unkey.com/docs；Stripe Metered Billing（按 API 调用次数扣费）：docs.stripe.com/billing/subscriptions/usage-based

双重市场宣传手段

嵌入式动态徽章：用户接入就生成徽章代码，贴自己官网首页炫耀真实数据，域名权重一个月内飙升，顺着外链爬过来的 AI Bot 会呈指数级增长。

抢占“机器应用商店”：接口提交到 Official MCP Registry、Smithery.ai、Glama MCP Directory 与 Apify Store。

/stats 宏观统计页：把库里数据汇总成实时更新的统计页，把极具冲击力、反直觉的真实数据截图发到 X 和 Reddit，每次都能引发上千次转发。

拿爬虫日志谈 B2B 赞助：别聊虚无的 PV，直接截图 Cloudflare 后台——过去 30 天，三大模型的检索爬虫抓了这个细分品类页面多少次，问金主想不想把品牌写进置顶 JSON-LD。

结语

Agent 正在成倍增长，在主人睡觉时工作，按次付费。

不需要百人团队，不需要销售漏斗，只需要一份 agent 每天都想查的数据。
