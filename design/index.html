附录：怎么把网页做到顶级好看

好看不靠灵感，靠几条能重复执行的规则。下面是原理、抄法，和 10 个值得收藏的链接。

原理：顶级网站共有的 7 件事

不管哪种风格，这 7 条都成立。先守住它们，再谈风格。

  • 层级每一屏只有一个最大的东西。字号、字重、颜色各分三档就够，再多就乱。
  • 间距全站只用一把尺：4 或 8 的倍数。相关的靠近，无关的拉开；拿不准，就把留白翻倍。
  • 字体最多两款。正文每行 45–75 个英文字符（中文 28–38 字），行高 1.5–1.7；标题行高 1.0–1.2。
  • 颜色先做黑白稿，再加一个强调色。中性色占九成；不用纯黑纯白，灰色里带一点强调色的色相。
  • 对齐所有元素贴同一组栏线。圆角、边框、阴影各只留一套数值。
  • 细节悬停、聚焦、按下、禁用四种状态都要做；动效 150–300ms；用真实文案和真实图片。
  • 记忆点顶级网站都只在一个地方大胆：一款字体、一个颜色或一个动效。其余全部克制。

怎么抄：5 步，抄结构不抄素材

抄的是网格、层级和数值。对方的 logo、插画、文案、照片不要搬。

  1. 选定 1 种风格和 2 个参考站。每个站截 3 张图：首屏、一个内容区、页脚。
  2. 量用浏览器开发者工具量出设计令牌：字体、字号阶梯、行高、底色、文字色、强调色、间距、圆角、栏宽。
  3. 写把风格名、3 条做法启示、令牌数值、参考站 URL、不要做什么，一起写进 prompt。也可以存成一份 DESIGN.md，以后每次直接交给 AI。
  4. 换网格、层级、节奏、比例照抄；文字、图片、品牌色、字体全换成自己的。
  5. 比把成品截图和参考站并排，逐项对字号、留白、对比度，改到差距看不出来。

10 个值得收藏的链接

前 5 个讲原理，中间 2 个讲工艺和 AI prompt，后 3 个是找参考的库。

  1. Refactoring UI

    Adam Wathan 和 Steve Schoger 写给不会设计的开发者的书。层级、间距、配色，全是能直接照做的招。

    refactoringui.com
    原理
  2. Visual design rules you can safely follow every time

    Anthony Hobday 的安全规则清单：不用纯黑纯白、灰色带一点色相、间距成比例。可以当检查表，逐条对 AI 的产出。

    anthonyhobday.com/sideprojects/saferules
    原理
  3. 7 Rules for Creating Gorgeous UI

    Erik Kennedy 的七条规则：先做黑白稿、留白翻倍、只用好字体。第七条就是「像艺术家一样偷」。

    learnui.design/blog
    原理
  4. Butterick’s Practical Typography

    免费在线书。先读「十分钟学会排版」那一页，正文字号、行宽、行高的数字都在里面。

    practicaltypography.com
    字体
  5. Laws of UX

    Jon Yablonski 整理的设计心理学法则，解释为什么这样排更好用、更好看。

    lawsofux.com
    原理
  6. Web Interface Guidelines

    Vercel 的界面细节清单：交互、动效、布局、表单逐条列出。做完一页，拿它来验收。

    vercel.com/design/guidelines
    工艺
  7. Improving frontend design through Skills

    Claude 官方博客：怎么写 prompt 和 Skill，让 AI 做出不千篇一律的前端。和这页的「做法启示」配着用。

    claude.com/blog
    AI prompt
  8. Awwwards

    网页设计奖项，有每日网站和年度网站。找顶级参考，从这里的获奖名单开始翻。

    awwwards.com
    参考库
  9. Mobbin

    真实产品的界面截图库，按页面类型和组件搜。适合抄结构：定价页、注册流程、空状态。

    mobbin.com
    参考库
  10. Fonts In Use

    按字体查真实案例。看中一个站，先来这里查它用的是什么字。

    fontsinuse.com
    字体
